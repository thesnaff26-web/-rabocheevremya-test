Снимок содержит все файлы репозитория на момент создания. Это резервная копия исходников приложения. Маршруты, записанные пользователями в локальном хранилище телефонов, не входят в GitHub-снимок; обновление их не изменяет.

Не требуется удалять данные сайта, переустанавливать PWA или стирать локальные маршруты. Сохранённую ветку не использовать для дальнейшей разработки.

## Два слоя данных

- `rail/route-geometry.geojson`: подробные рельсовые линии OSM, включая станционные пути.
- `rail/corridor.json`: существующие архивные опорные точки км/ПК и прочие данные раздела.

`rail/geometry.js` связывает вершины рельсовой линии с ближайшими архивными отрезками через пространственный индекс. Сегменты с неоднозначными опорными точками, чрезмерным скачком километража или неподходящей геометрией исключаются. Внутри оставшегося сегмента км/ПК интерполируется по архивной привязке. Это экспериментальная привязка, не новая официальная километровая база.

GPS сопоставляется с подробной геометрией в диапазоне 6895–7215 км. При равнозначных вариантах с существенно различным километражом показание отклоняется. История принятой позиции ограничивает скачки и помогает выбирать последовательный вариант. Конкретный станционный путь и чётность автоматически не подтверждаются.

Порог точности телефона — до 40 м. При 26–40 м выводится пометка о пониженной точности. Близость к рельсовой линии проверяется отдельно; повышение порога телефона не отменяет эту проверку.

Км/ПК остаётся приблизительным. Совпадение GPS с линией OSM в пределах нескольких метров не означает такую же точность километража. В интерфейсе показано происхождение архивной привязки. Независимой проверенной километровой опоры для всего участка пока нет.

Вне покрытия новой геометрии, а также при ошибке её загрузки, используется прежняя архивная линия с соответствующим сообщением. Файл геометрии проверяется SHA-256. Новый Service Worker активируется после сохранения полного набора файлов раздела, включая геометрию. Для неё ограничено время загрузки тела ответа. Запросы к OSM при включении GPS не выполняются: используется статический файл приложения. Координаты телефона через этот механизм на сервер не отправляются.

Локальные пользовательские GPS-привязки сохраняются под отдельным прежним ключом `rail-local-gps-anchors-v1`. При их сохранении или сбросе пространственный индекс обновляется. Ключи маршрутных записей, расчёт времени и основной экран приложения не изменены.

## Проверки

Из корня проекта:

```sh
node tests/rail-geometry.test.cjs
```

Проверяются кривая вдали от старой хорды, приём GPS с точностью 32 м с пометкой, отклонение 41 м, скачки положения, грубый обзор, отклонение точек вне линии, резервная архивная линия, обновление локальной привязки, целостность реального набора геометрии. Проверка на синтетических данных не заменяет испытания на устройстве в поездке.

Пересборка файла:

```sh
python3 scripts/build-rail-geometry.py --download --runtime
```

После пересборки необходимо обновить ожидаемый SHA-256 в `rail/app.js`, версию Service Worker и повторить проверки. Источник и лицензия ODbL сохранены в метаданных. Атрибуция OpenStreetMap отображается в интерфейсе.
